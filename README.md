# Dragon da Programação: Desvende os Heróis do Código! 🐉💻

Prepare-se para mergulhar em um universo onde a programação encontra o poder de dragões (ou quase isso 😉)! 
Este projeto apresenta uma galeria de heróis digitais, cada um com suas habilidades únicas no mundo do código. 
Clique nos ícones e descubra quem são esses mestres da tecnologia!

## Sobre o Projeto

A ideia aqui é criar uma experiência visualmente interessante para apresentar diferentes "personagens" do mundo da programação, cada um com sua própria história e estilo. 
Usamos HTML, CSS e JavaScript para construir essa galeria interativa, onde ao clicar em um ícone, o personagem correspondente ganha destaque com sua imagem e descrição.

## Tecnologias

Construímos essa aventura digital com:

* **HTML**: A espinha dorsal da nossa página, estruturando o conteúdo e os elementos.
* **CSS**: O toque de magia visual! Responsável por toda a estilização, desde o layout até as animações sutis ao selecionar um herói.
* **JavaScript**: O motor que dá vida à interação! Ele detecta os cliques nos ícones e atualiza a exibição do personagem correspondente.

## Como Usar

1.  Clone este repositório.
2.  Abra o arquivo `index.html` no seu navegador.
3.  Na lateral direita, você verá ícones representando cada herói.
4.  Clique em um ícone para destacar o herói correspondente na tela principal, com sua imagem e descrição.

## Funcionalidades

* **Seleção de Heróis:** Clique nos ícones laterais para escolher qual mestre da programação você quer conhecer.
* **Destaque Visual:** Ao selecionar um herói, sua imagem e descrição ganham destaque na tela principal.
* **Design Responsivo:** A aplicação foi pensada para funcionar bem em diferentes tamanhos de tela.
